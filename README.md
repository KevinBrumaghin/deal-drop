# Deal Drop

Tech deals blog — gaming, PC, smart home, and appliances. Hand-picked deals with
genuine commentary, published as Amazon Associates affiliate links.

- `index.html` — the entire site (single self-contained file, mobile-first)
- Built with Muse; updated automatically by an hourly deal sweep

## Hosting

Connected to Netlify for hosting on a custom domain. Every push to `main`
triggers a fresh deploy.

## Affiliate disclosure

As an Amazon Associate, Deal Drop earns from qualifying purchases.
